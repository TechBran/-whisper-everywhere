OpenAI Whisper models — MIT License. The speech-recognition model weights (all tiers).
OpenAI Whisper tokenizer vocabulary — Apache License 2.0. The byte-level BPE vocabularies bundled with this app. The whisper-small one is built from vocab.json and added_tokens.json of the openai/whisper-small model repository, whose model card declares license: apache-2.0. The large-v3-turbo one (whisper_vocab_turbo.json) is a derived work: the two model families share their 50,257-token base table, so it is the whisper-small vocabulary above with the turbo family's special-token layout (one added language, <|yue|>), and it is verified at build time against the vocab.bin tokenizer table published in Qualcomm AI Hub's whisper-large-v3-turbo package (also Apache License 2.0). This is tokenizer data, not model weights, and it is licensed separately from the weights above. huggingface.co/openai/whisper-small
OpenAI Whisper mel filterbank (128-band) — MIT License for the model data, Apache License 2.0 for the ggml conversion tooling that produced its layout. The bundled melbank-128.bin is a derived work: it is the first 102,968 bytes of the ggml conversion of openai/whisper-large-v3-turbo — the file header, the model hyper-parameters and the 128 × 201 mel filterbank matrix — and nothing else. It contains no model weights and no vocabulary. It is bundled because the mel spectrogram for the 128-band speech models is computed from this matrix, and shipping it avoids requiring the 574 MB model file it was taken from. huggingface.co/openai/whisper-large-v3-turbo
Silero VAD — MIT License. Voice-activity detection model. github.com/snakers4/silero-vad

Live words (the streaming preview)

When you pick a language, a second, small speech model can run beside the one above and put words on the bubble as you speak. It never writes your transcript — the model above does that. Each language is a separate download; the licence below is the one its publisher declares for those weights, and the runtime is the sherpa-onnx listed under Read-aloud.

Streaming Zipformer — French (shaojieli) — Apache License 2.0. Trained on Common Voice 12.0 French (CC0) over a LibriSpeech (CC BY 4.0) pre-training, with attribution to the authors named above. huggingface.co/shaojieli/sherpa-onnx-streaming-zipformer-fr-2023-04-14
Streaming Zipformer — German (daniel-dona) — Apache License 2.0, as declared by its publisher. Trained on Common Voice 17.0 German. huggingface.co/daniel-dona/icefall-asr-commonvoice-zipformer-streaming-de
Streaming Zipformer — Russian (alphacep) — Apache License 2.0. The files are the ONNX export mirrored by csukuangfj; they are byte-for-byte the weights published as vosk-model-small-streaming-ru, which is where that licence is declared. huggingface.co/alphacep/vosk-model-small-streaming-ru

Bundled audio

Short speech clips are bundled so the app can verify, at load time, that a speech model on this device transcribes correctly before its words are shown.

FLEURS (Google) — Creative Commons Attribution 4.0 International (CC BY 4.0). Four of these clips are single utterances from the google/fleurs speech corpus, used with attribution to its authors: canary_de_fleurs.wav (German, de_de validation item 1528), canary_ru_fleurs.wav (Russian, ru_ru 1587), canary_id_fleurs.wav (Indonesian, id_id 1636) and canary_ko_fleurs.wav (Korean, ko_kr 1636), taken from dataset revision 70bb2e84. Changes were made, as CC BY 4.0 requires us to state: each clip was converted to 16 kHz mono PCM and shortened to between three and five seconds. The full corpus and its licence are at huggingface.co/datasets/google/fleurs, and the licence text at creativecommons.org/licenses/by/4.0/
Kokoro-82M (hexgrad) — Apache License 2.0. canary_fr_digits.wav is not a recording: it is speech generated with the read-aloud voice model listed above (voice ff_siwis), so the Apache-2.0 grant on those weights is the only licence it carries.
canary_digits.wav — recorded by the author of this app. No third-party rights.
