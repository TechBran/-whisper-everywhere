### The seven paid-for lessons (binding — each cost a device round trip)

1. **`<uses-native-library ... required="false"/>`** for `libcdsprpc.so` + `libadsprpc.so`.
   Without it Android 12+ refuses the FastRPC library and the HTP silently never comes up.
   `required="false"` so the app still installs on every device.
2. **`Qnn_Tensor_t` is not self-contained.** `name` and `dimensions` are pointers owned by the
   system context. Deep-copy everything you keep, and do not free the system context early.
3. **Never `#ifdef` an enumerator.** `QNN_TENSOR_VERSION_*` are enum constants; `#ifdef` is always
   false and silently compiles the branch out.
4. **Version every versioned struct, loudly.** Binary-info v1/v2/v3, graph-info v1/v2/v3, tensor
   v1/v2 — handle the known set, fail by name on anything else, and print the version numbers even
   on success.
5. **Bind by NAME, never by index.** The decoder has 51 inputs; build a name→index map from the
   enumerated metadata.
6. **A vote that fails silently looks exactly like slow silicon.** Report the vote result on its
   own line, always.
7. **Own the buffers, 64-byte aligned, in an RAII type with copy deleted.** A `vector<vector<>>`
   reallocation invalidates a pointer QNN already holds.

## Measured ground and BAKED asset facts

The spike (9 runs) settled the architecture and the numbers: encoder **404.6 ms sustained** /
369.2 burst, cold load **525 ms**, 26 ms bands, zero thermal drift. The seam is raw QNN, owned.

Everything below was parsed out of the real asset while writing this plan. **It is not
first-contact for the implementer** — bind against these facts, and let the loud-stage reader
confirm them at load.

### Asset pair (`whisper_small_quantized-precompiled_qnn_onnx-w8a16-qualcomm_snapdragon_8gen3.zip`)

| File | Bytes | Role |
|---|---|---|
| `encoder_qairt_context.bin` | 132,927,488 | encoder context binary (already proven on device) |
| `decoder_qairt_context.bin` | 225,316,864 | decoder context binary (**new in 4.0**) |

Both carry `binary_info_version 3`, `graph_info_version 3`, tensor **v2**, blob QAIRT
`v2.45.0.260326154327`, `socModel 57` (SM8650 / HTP v75). One graph each; the encoder graph is
named `whisper_small_quantized_encoder`.

### Encoder IO (confirmed on device, run 7–9)

- **in** `input_features` `ufixed16 [1,80,3000]` = 480,000 B, scale `4.677007018472068e-05`,
  zero_point `32072`
- **out** 24 × cross-KV `ufixed8`: `k_cache_cross_0..11` `[12,1,64,1500]`,
  `v_cache_cross_0..11` `[12,1,1500,64]`, 1,152,000 B each = **27,648,000 B (26.37 MiB)**

### Decoder IO — 51 inputs, 25 outputs (parsed from `metadata.json`; graph is one EPContext node)

| Group | Count | Shape / dtype | Bytes each |
|---|---|---|---|
| `input_ids` | 1 | `int32 [1,1]` | 4 |
| `position_ids` | 1 | `int32 [1]` | 4 |
| `attention_mask` | 1 | `uint16 [1,1,1,200]` | 400 |
| `k_cache_self_N_in` | 12 | `uint8 [12,1,64,199]` | 152,832 |
| `v_cache_self_N_in` | 12 | `uint8 [12,1,199,64]` | 152,832 |
| `k/v_cache_cross_N` | 24 | `uint8` as encoder outputs | 1,152,000 |
| **out** `logits` | 1 | `uint16 [1,51865,1,1]` | 103,730 |
| **out** `k/v_cache_self_N_out` | 24 | mirrors the `_in` shapes | 152,832 |

Total in **31,316,376 B**, total out **3,771,698 B**.

**Four consequences that shape the design — bake them in:**

1. **Cross-KV is bound ONCE, never re-copied.** The decoder's 24 cross-KV inputs are
   byte-identical in shape, scale and zero_point to the encoder's 24 outputs (verified pairwise:
   e.g. `k_cache_cross_0` scale `0.06918466091156006`, zp `128`, both sides). **Alias the same
   `AlignedBuf`s** — the encoder writes them, the decoder reads them, zero copy. Naively re-feeding
   them per token would move 26.4 MiB × ~100 tokens ≈ 2.6 GB per segment.
2. **Self-KV ping-pongs; it is never memcpy'd.** `_in` and `_out` scales match per layer (e.g.
   `k_cache_self_0` `0.06397456675767899` on both), so no requantisation between steps. Allocate
   **two** sets of 24 buffers (2 × 3,667,968 B = 7.0 MiB) and **swap the pointers** each step by
   re-binding the client buffers. QNN cannot alias one buffer as both input and output.
3. **The asset caps context at 200 tokens.** Self-KV depth is 199 (+1 current) and the mask is
   `[1,1,1,200]`. Whisper's own `max_length` is 448 — **the asset's 200 wins**; clamp there and
   treat the cap as a normal terminal condition, not an error.
4. **Greedy argmax runs directly on the quantised `uint16` logits.** Dequantisation is affine with
   a positive scale, so it is monotonic and cannot reorder an argmax. Do not dequantise 51,865
   values per token to pick a maximum.

`attention_mask` quantisation is exact and worth hardcoding as derived constants:
scale `0.0015259021893143654`, zp `65535` → **attend = `65535`, masked = `0`**
(`0.0015259021893143654 × -65535 = -100.0`, whisper's mask value).

### Tokenizer (`openai/whisper-small`, **Apache-2.0** — license-checked)

`vocab.json` + `merges.txt` + `added_tokens.json`. Vocab **51865** (not 51866 — that is
large-v3/turbo; the brief's figure does not apply here, and the decoder's `logits` dimension
confirms it).

Special ids: `<|startoftranscript|>` **50258**, `<|endoftext|>` **50257**, `<|translate|>` **50358**,
`<|transcribe|>` **50359**, `<|startoflm|>` 50360, `<|startofprev|>` 50361, `<|notimestamps|>`
**50363**, timestamps begin `<|0.00|>` **50364**. Languages are `50259 + index`
(`<|en|>` 50259, `<|zh|>` 50260, `<|de|>` 50261, `<|es|>` 50262, `<|fr|>` 50265).

`generation_config.json` gives the authoritative suppression sets:
`begin_suppress_tokens = [220, 50257]` and an 88-entry `suppress_tokens` list — copy it verbatim
into `WhisperTokens.SUPPRESS` in Q4 (its first entries are
`[1, 2, 7, 8, 9, 10, 14, 25, 26, 27, 28, 29, 31, 58, 59, 60, 61, 62, 63, 90, 91, 92, 93, 359, …]`
and it ends `…, 50254, 50258, 50358, 50359, 50360, 50361, 50362]`).

### Memory budget (for the Q10 RSS read)

127 MiB encoder + 215 MiB decoder context binaries, + 26.4 MiB cross-KV + 7.0 MiB self-KV
ping-pong + 0.5 MiB mel/logits ≈ **376 MiB** of NPU-side residency, before whisper.cpp's `multi`
context (the fallback) is considered. Tear `multi` down before arming NPU; never co-resident.

## Task Q4 — The decoder: baked IO, self-KV ping-pong, greedy loop  **[NATIVE]**

**Files**
- `app/src/main/cpp/qnn_asr.cpp` (edit)
- `app/src/main/java/com/whispereverywhere/npu/WhisperTokens.kt` (new)

- `app/src/test/java/com/whispereverywhere/npu/NpuDecodePolicyTest.kt` (new)

**Steps**

1. **Bind by name.** Build a `map<string,int>` from the enumerated metadata for all 51 inputs and
   25 outputs. Never index positionally (lesson 5) — with 51 inputs an off-by-one is a silent
   wrong answer, not a crash.
2. **Cross-KV: bind once at init to the encoder's output buffers.** Zero copy, never rewritten per
   token.
3. **Self-KV: two buffer sets, swap by re-binding.** Step *n* binds set A as `_in` and set B as
   `_out`; step *n+1* swaps. Never memcpy 3.6 MiB per step, and never alias one buffer as both.
4. **`attention_mask`**: fill with the derived constants — `65535` for positions `0..pos`
   (attend), `0` for the rest (masked = −100.0).
5. `nativeDecodeStep(tokenId, position)` writes `input_ids` and `position_ids` (both plain
   `int32`, un-quantised), executes, then **argmaxes the raw `uint16` logits directly** — no
   dequantisation, because the affine transform is monotonic. Returns the argmax token id, or a
   negative error code.
6. `nativeResetDecode()` zeroes both self-KV sets and the mask. Cross-KV survives — it belongs to
   the current segment's encode.
7. `WhisperTokens` carries the pinned constants and the verbatim 88-entry `SUPPRESS` list plus
   `BEGIN_SUPPRESS = [220, 50257]` from the baked facts above.
8. `NpuDecodePolicy` is the **pure, JVM-testable brain** of the loop, deliberately separated from
   the native call so it can be tested for real:
   - `promptTokens(lang)` = `[SOT, langToken(lang), TRANSCRIBE, NO_TIMESTAMPS]`
   - `isSuppressed(id, step)` = `id in SUPPRESS || (step == 0 && id in BEGIN_SUPPRESS) ||
     id >= TIMESTAMP_BEGIN` (we prompt `<|notimestamps|>`, so a timestamp token is a decode fault)
   - `isTerminal(id, step)` = `id == EOT || step >= MAX_TOKENS`
   **`MAX_TOKENS = 200` comes from the asset, not from whisper.** Self-KV depth is 199; whisper's
   own `max_length` of 448 is unreachable here and clamping is a normal stop, not an error.

`220` suppressed at step 0 but allowed at step 3; every timestamp id ≥ 50364 suppressed at all

suppression id (`50361`) is caught.
