# Tab S10+ (MT6989) APU probe — E3 / E4-lite / E5 measurements

Device: Samsung Galaxy Tab S10+ SM-X828U, MediaTek MT6989 (Dimensity 9300), Android 16 / API 36, 12 GB,
Mali-G720 Immortalis MC12. Serial `192.168.1.161:44483` (wireless debugging). The Play copy of Whisper
Everywhere (`com.whispereverywhere`, versionCode 86 / 4.3.2) stayed installed and untouched throughout —
§7 proves it. Probe app: `tools/probes/litertlm-probe/` (`com.whispereverywhere.probe`, versionCode 1,
debuggable, minSdk 31), driven from the PC by `drive.py`; every run is a fresh process (`am force-stop`
before `am start`), so every "cold" number is a true process-cold start.

Experiments, thresholds and decision rules are those of
`docs/superpowers/research/2026-09-09-tab-turbo-gemma-scribe-gemini-live-research.md` §1.4 (E3, E4, E5)
and §7 (E0). Sessions: 2026-09-09 23:36–23:50 (first half, cut off by a session limit) and 2026-09-10
04:43– (this continuation). Raw logs: `C:/Users/bastr/.androidbuild/probe-logs/<tag>.{json,filtered.log,full.log}`
(outside the repo). Tables are generated by `tools/probes/litertlm-probe/summarize.py` from the JSON the
app writes; the prose quotes the logcat lines that prove which backend ran.

Timing convention: **`mean/median/min/max ms` are run+read** — `CompiledModel.run()` followed by
`outputBuffer.readFloat()` — because the GPU accelerator's `run()` returns before the OpenCL queue drains
(measured: 2–4 ms "runs" on Mali until the output is read; runs `e5_base_gpu_211_1/2` below still carry the
run-only timing and are kept for the record). `cold run ms` is the first invoke after `create` (run+read from
run 3 on). `create ms` is `CompiledModel.create()` — on the NPU that is where the JIT compile lands. RSS/PSS
are `/proc/self/status VmRSS` and `Debug.getMemoryInfo().totalPss`; battery temperature is
`BatteryManager.EXTRA_TEMPERATURE`/10; thermal is `PowerManager.currentThermalStatus` (0 = NONE, 1 = LIGHT).

toolchain gap in play — §3 (the AOT-compiled tiny artefact) is the control that separates the toolchain
from the silicon.
